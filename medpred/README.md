# MedPredict – Multiple Disease Prediction

Streamlit app with 9 ML screening models, doctor/admin sign-in, and a **Gemini** AI health advisor.

## Run
```bash
pip install -r requirements.txt
copy .env.example .env        # (Linux/Mac: cp)  then put your GEMINI_API_KEY inside .env
streamlit run app.py
```
The Gemini key is read only from `.env` (or real environment variables) — it is never shown or asked for in the UI.
Free key: https://aistudio.google.com/apikey . Restart the app after editing `.env`.

## Accounts
| Role | How |
|---|---|
| Doctor | Self-registers on the **Register** page (name, email, **mobile number**, medical registration no., password) and must agree to be listed in the public directory |
| Admin | Seeded on first start. Default `admin@medpredict.com` / `Admin@123` – **change it** in *Account*, or set `ADMIN_EMAIL` / `ADMIN_PASSWORD` in `.env` before first run |

Admins can disable/enable doctors, see every prediction, and view per-disease counts.
Users are stored in `data/medpredict.db` (SQLite, git-ignored). Passwords are PBKDF2-hashed; 5 wrong
attempts lock an account for 10 minutes. Prediction history stores the patient name you type in —
treat the DB as sensitive and don't commit it.

## Public access
Everyone can use the 9 screenings and the **Find a Doctor** directory without signing in. Login is only for doctors
(history, directory listing) and the admin (dashboard). Predictions made by signed-out visitors are *not* stored.
Gemini advice is capped per session (`AI_ADVICE_LIMIT_PER_SESSION` in `.env`, default 15) to protect your API quota.

## Model accuracy
After every prediction the app shows the model's accuracy plus the model's confidence for that result (when the model
can output one). Accuracy comes from `models/metrics.json`, produced by:
```bash
python training/evaluate_models.py          # all models whose dataset is in data/
python training/evaluate_models.py lung     # just one
```
It re-fits a copy of each saved model's configuration in 5-fold cross-validation (the .sav files are untouched).
Currently measured: lung, breast, diabetes, heart, symptom checker. For **parkinson, kidney, hepatitis, liver** put the
Kaggle CSVs from `training/README.md` in `data/` (`parkinsons.csv`, `kidney_disease.csv`, `hepatitis.csv`, `liver.csv`)
and run the command above; until then the app honestly shows "Not evaluated yet" for them.
Note: `data/dataset.csv` is the symptom dataset, not PIMA diabetes; the PIMA data is in `data/diabetes.csv`.

## Find a Doctor
A public page (no login) listing active doctors who opted in, with tap-to-call phone and email links, plus search and
specialization filter. Admins can disable a doctor (removes them from the directory); doctors can change their number
or un-list themselves under *Account*.

## Flow
Landing page → click a disease card (e.g. Lung Cancer) → straight to that prediction page → result with model accuracy and Gemini guidance.

## Layout
```
app.py                 routing, pages, prediction forms
core/gemini_advisor.py Gemini integration (replaces the old Groq module)
core/auth.py           SQLite users, login, registration, audit log
core/ui.py             theme + image helpers
assets/                illustrations (generated by tools/make_assets.py)
```
(`code/` was renamed to `core/` because `code` clashes with Python's built-in module.)
